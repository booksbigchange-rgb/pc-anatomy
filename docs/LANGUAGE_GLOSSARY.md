## Style

- Use short sentences.
- One idea per sentence.
- Prefer student-friendly examples.
- Avoid invented translations for familiar hardware acronyms.
- Do not make the translated explanation more technical than the English source.
- When a direct translation sounds unnatural, preserve the technical term and explain it naturally.
