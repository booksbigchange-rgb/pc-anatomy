# BigChange Academy — hardware lab classroom check

Teacher Hermon Tesfay · 15–20 minutes · 3–5 learners

Use one older computer and one phone. Open the public preview. Use Light graphics if the model feels slow. Students can drag parts or use Seat in its guide. Do not record student names.

## Student tasks

1. Find a USB port. Say what connects to it.
2. Start PC assembly. Try seating the CPU in the wrong direction. Read the feedback, turn it, and try again.
3. Install the remaining parts. Apply paste before the cooler. Secure the clips, screw, card bracket and cooler corners.
4. Match the cables. Close the cage and cover. Test power. Fix any reported problem.
5. Open Task Manager. Run Copy files, then end it. Compare Disk before and after. Where do saved files stay?
6. In Troubleshooting, choose a test, read the evidence, apply the matching fix and run the check again.

Record device/browser, time to load, noticeable freezes, confusing words and unsuccessful taps. Mark each row Pass, Needs help or Failed. Browser automation is not a substitute for these observations.

## Visual review

Check the assembled and exploded laptop and desktop. Verify that CPU/cooling alignment, RAM contacts, SSD socket, speakers and cable routes look believable. Interior measurements are estimated, not measured CAD. Decorative small board parts are not all individually selectable.

## Decision

Ready for a supervised lesson only when the essential tasks pass on the intended devices. Record remaining issues before opening a new chapter. Real repair procedures, force and torque are outside this simulator.
